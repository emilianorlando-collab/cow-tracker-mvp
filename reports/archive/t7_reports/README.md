# Reportes Historicos del T7

Esta carpeta contiene reportes livianos recuperados de la carpeta local del T7.

Se versionaron:

- Reportes `.json`.
- Contact sheets y candidate sheets `.jpg`.
- Reportes `.md` y `.txt`.

No se versionaron:

- Caches `.pkl`.
- Videos.
- Zips.
- Datasets pesados.
- Metadatos de sistema.

mezclar las pruebas historicas con el resultado final aprobado.
