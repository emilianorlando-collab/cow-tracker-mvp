# Reportes Intermedios

Esta carpeta conserva pruebas representativas previas al resultado final.

Incluye:

- Analisis de timeline sobre Erondina.
- Contact sheets y candidate sheets de pruebas de Re-ID.
- Reportes JSON usados para comparar estabilidad temporal y candidatos.

Estos archivos no reemplazan a los reportes finales. Su funcion es documentar
el proceso experimental y mostrar como se llego al pipeline aprobado.
