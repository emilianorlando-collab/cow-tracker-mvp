# Resultado final de la aplicación web

La corrida final valida el conteo y la reidentificación sobre el clip de prueba
de la interfaz.

Archivos:

- `cowtrack_webapp_reid_color_final.json`: métricas técnicas públicas.
- `cowtrack_webapp_reid_color_final.pdf`: informe ejecutivo descargable.
- `cowtrack_webapp_reid_color_evidencia.jpg`: evidencia visual de las tres
  identidades.
- `cowtrack_webapp_reid_color_candidatos.jpg`: candidatos evaluados por el
  pipeline.

El video no se incluye en Git por su tamaño. La interfaz lo genera y conserva en
el almacenamiento local configurado.
