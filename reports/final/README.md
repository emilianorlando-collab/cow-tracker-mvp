# Reportes Finales

Esta carpeta contiene los artefactos finales usados para validar el MVP.

Archivos principales:

- `17_resultado_final_reconteo.json`: reporte final publico del reconteo.
- `17_resultado_final_reconteo_contact_sheet.jpg`: visualizacion final de
  continuidad e identidades.
- `17_resultado_final_reconteo_preview_frames/`: frames de verificacion visual
  del inicio, mitad y final del render.

Los archivos `16_*` se conservan como antecedente tecnico del render anterior.
El resultado vigente para presentacion y metricas es el reporte `17_*`.

Esta carpeta debe mantenerse reservada para resultados finales aprobados. Las
pruebas historicas o exploratorias deben quedar en `reports/intermediate/` o
`reports/archive/`.
