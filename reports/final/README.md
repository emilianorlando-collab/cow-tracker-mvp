# Reportes Finales

Esta carpeta contiene los artefactos finales usados para validar el MVP.

Archivos principales:

- `16_erondina_final_render.json`: reporte operativo del render final.
- `16_metricas_calculadas_desde_json.json`: metricas finales derivadas del
  reporte JSON.
- `16_erondina_final_contact_sheet.jpg`: visualizacion de continuidad e
  identidades.
- `16_erondina_final_candidate_sheet.jpg`: evidencia visual de candidatos Re-ID.
- `16_erondina_final_render_preview.jpg`: vista previa del render final.

Esta carpeta debe mantenerse reservada para resultados finales aprobados. Las
pruebas historicas o exploratorias deben quedar en `reports/intermediate/` o
`reports/archive/`.
