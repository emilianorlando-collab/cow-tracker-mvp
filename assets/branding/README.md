# Identidad visual CowTrack

Variantes oficiales utilizadas por la interfaz web y la documentación:

- `cowtrack-logo-dark.svg`: logotipo para fondos claros.
- `cowtrack-logo-light.svg`: logotipo para fondos oscuros.
- `favicon.svg`: isotipo compacto para navegador.
- `cowtrack-logo-primary.png`: variante raster principal.
- `cowtrack-logo-light.jpg`: variante raster clara.
- `cowtrack-logo-source.png`: fuente raster optimizada para Git.
- `cowtrack-brand-board.jpg`: referencia visual de la marca.

Los SVG de `mockup/static/` siguen siendo los recursos utilizados directamente
por la aplicación. Esta carpeta funciona como biblioteca de marca para informes,
presentaciones y futuras integraciones.
