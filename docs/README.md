# Documentacion Tecnica

Esta carpeta contiene documentacion complementaria al README principal.

Archivos principales:

- `ERONDINA_REID_PIPELINE.md`: describe el pipeline final de Re-ID aplicado al
  caso Erondina, sus comandos, metricas y decisiones tecnicas.
- `SCRIPTS_INTERMEDIOS.md`: resume el rol de los scripts historicos que fueron
  creados durante la investigacion.

El README principal del repositorio debe leerse primero. Esta carpeta funciona
como extension tecnica para explicar decisiones, ejecucion y trazabilidad.
